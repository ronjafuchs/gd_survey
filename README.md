# Supplementary Material for "How do Players perceive Gender Discrimination? On the Differences of Harassment in Online Games"

This repository contains supplementary material for the paper **"How do Players perceive Gender Discrimination? On the Differences of Harassment in Online Games"**. 
The provided files include survey structures, result data, and pattern recognition files used in the research.

## Repository Contents

### 1. Survey Structures

- `survey_structure/s1_export.pdf`: The structure of the first survey, including questions and response options.

- `survey_structure/s2_general_export.pdf`: The structure of the second survey.
- `survey_structure/s2_valorant_export.pdf`: The structure of the second survey, customized for VALORANT.

### 2. Survey Results

- `results/results-s1_15012025.csv`: Results of the first survey.
- `results/results_s2_general_16022025.csv`: Results of the second survey.
- `results/results_s2_valorant_16022025.csv`: Results of the second survey, customized for the r/VALORANT subreddit.
- `results/results_s2_cs2_16022025.csv`: Results of the second survey, from the r/CS2 subreddit.

### 3. Pattern Recognition Files

- `pattern_recognition_s1.ipynb`, `pattern_recognition_s2.ipynb`: Files used for detecting patterns in responses for exclusion from the analysis.
